## 👨🏻‍💻 About me

I'm a hands-on Full-Stack Developer with 9+ years shipping production web applications and a B.Sc. in Computer Science from the State University of Paraíba (UEPB). I build with React, TypeScript and Python, design and integrate REST APIs, and deploy what I build. For nearly 5 years at Compass UOL, a global technology consultancy, I delivered React and TypeScript applications for clients with up to 20M+ users. Today I'm focused on AI-powered features: LLM integrations, RAG and chat interfaces that people actually use.

One of the projects that shaped me came early, at university: as a developer in the ATLAS research group, I built an educational game to help children with dyslexia train auditory perception and memory. Seeing software make a real difference for those kids is what still drives how I work today: understand the real problem first, then build something people actually use.

## 🚀 What I do

- **Full-stack product engineering:** React and TypeScript front-ends, Python and Node.js back-ends, REST APIs, and Docker deployments. As founder of OnlineTec Solutions, I've delivered 30+ websites and 5 SaaS systems end to end
- **AI-powered features:** OpenAI API, RAG pipelines with LangChain, streaming chat interfaces (SSE) and structured outputs validated with Pydantic
- **Quality and performance:** raised test coverage from 87% to 92% (Jest, React Testing Library), cut LCP from 4.2s to 2.1s, and built 80 Design System components that reduced duplicated code by 35%
- **Automation:** dynamic AMPscript templates on Salesforce Marketing Cloud that let a 7-person CRM team work without depending on a developer
- **Agentic coding:** Cursor, GitHub Copilot and Claude Code to ship faster, while I own the architecture and review every change
